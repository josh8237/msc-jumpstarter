# My Summer Car - JumpStarter Mod

This repository contains a My Summer Car mod that implements realistic jumper-cable jump-starting for the Satsuma and other vehicles using MSCLoader 1.4.2.

Supported game version: My Summer Car build 250908-04 (as requested)
MSCLoader target: 1.4.2

Contents
- /src - C# source files
- JumpStarter.csproj - Visual Studio project file
- mod.json - mod metadata for MSCLoader
- README.md - this file
- .gitignore

Build instructions are in the README.md.

NOTE: You must compile this project against the game's Managed assemblies (UnityEngine.dll, Assembly-CSharp.dll, MSCLoader.dll, HutongGames.PlayMaker.dll) which are found in the game's "Managed" folder. See README for details.
